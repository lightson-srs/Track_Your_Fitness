HOW TO RUN
──────────
The app must be served over HTTP (not opened as a file)
for service worker / auto-update / PWA install to work.

WINDOWS:
  Double-click  start-server.bat
  Browser opens automatically at http://localhost:8080

MAC / LINUX:
  Double-click  start-server.sh   (or run in terminal)
  Then open     http://localhost:8080

REQUIRES:  Python 3  (free, https://python.org)
           OR Node.js (free, https://nodejs.org)

──────────────────────────────────────────────
HOW TO UPDATE
──────────────
1. Extract new Track_Your_Fitness.zip over this folder
2. If server is running, stop it (Ctrl+C) and restart
3. Open http://localhost:8080 — app auto-reloads

──────────────────────────────────────────────
INSTALL AS APP ON PHONE
────────────────────────
1. Open http://YOUR-PC-IP:8080 on your phone
   (find your PC IP: run  ipconfig  in Command Prompt)
2. Android Chrome: menu → Add to Home Screen
3. iOS Safari:     Share → Add to Home Screen
